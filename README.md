# MONOMOONAP

[Archipelago Multiworld](https://archipelago.gg) implementation for MONOMOON, a 2D platformer and metroid"brain"ia.

Developed by @XuaTheGrate (Maya) and @chickentuna.
Custom assets drawn by DragonSlayr15001 on Discord.

## What is randomized?

In it's current state, the following items are randomized:
- 28 Orbs (7 for each colour).
- 29 Quills (excluding the Tome).
- The Map, Conch, Lyre and Map Markers.
- - The map can be started with in a yaml option.
- 5 Golden Quills.
- 8 Relics.
- 4 Moon Fragments.
- - These have been adjusted to be Progressive instead of unique.
- 3 Dragon Emblems and Crown Emblem.

For future plans, see [this spreadsheet](https://docs.google.com/spreadsheets/d/1uY03sKdkJLApEulmUSpIVjTy7WQaMYTs8QA-ld8FVaY/edit?usp=sharing)

## Setup Guide

1. Download the [latest mod release](https://github.com/XuaTheGrate/MONOMOONAP/releases).
2. Extract the files into your MONOMOON installation folder.
3. Download and install the [latest APWorld release](https://github.com/chickentuna/MonomoonApworld/releases).
4. Create your YAML via Archipelago's ``Options Creator``.
5. Connect and have fun!
